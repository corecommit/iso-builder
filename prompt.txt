## 1. Fix the "Not found" Spam
In `discover_isos()`, if a hardcoded path (like `~/Downloads` or `~/Desktop`) does not exist, simply `continue;` and do NOT add it to the `debug` report. Only report folders that actually exist and were scanned.

## 2. Add Smart Deep Scan (`[f]` key)
If the user's ISO is buried in `D:\ISOs\Linux\` or `/mnt/backup/cachy.iso`, the standard scan will miss it. Add a `[f]` key on the ISO step to trigger a Deep Scan.

**Deep Scan Rules:**
- **Target:** Search the entire filesystem starting from root (`/` on Linux/macOS, or all valid drive letters like `C:\`, `D:\` on Windows).
- **Speed Filter:** ONLY include files that end in `.iso` AND have a size > 500 MB (`500 * 1024 * 1024` bytes). This skips tiny bootable utilities.
- **Aggressive Pruning (CRITICAL):** You MUST skip OS system folders. Use `walkdir`'s `filter_entry()` to instantly skip these:
  - **Linux/macOS:** `proc`, `sys`, `dev`, `run`, `tmp`, `usr`, `var`, `lib`, `lib64`, `bin`, `sbin`, `etc`, `boot`, `snap`, `.cache`, `.git`, `node_modules`.
  - **Windows:** `Windows`, `Program Files`, `Program Files (x86)`, `ProgramData`, `AppData`, `$Recycle.Bin`, `System Volume Information`, `Recovery`.
- **Threading:** Run the deep scan in a separate thread using `std::thread::spawn`. Send the results back through an `std::sync::mpsc::channel`. 
- **UI State:** 
  - Add `deep_scan_rx: Option<Receiver<Vec<IsoEntry>>>` to `App`.
  - When `[f]` is pressed, show a loading state ("🔍 Deep scanning for ISOs > 500MB... Skip system folders. Press [Esc] to cancel.").
  - In the main `event_loop`, use `try_recv()` to check if the background thread has finished.
  - Once received, update `discovered_isos` and clear the loading state.
